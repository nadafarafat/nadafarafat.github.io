Work

01
BD Alaris 8015 Firmware Security Analysis
Comprehensive firmware security analysis of an FDA-flagged infusion pump (CVE-2016-9355). Identified 6 compound OT vulnerabilities including plaintext credential storage and disabled integrity verification. Applied STRIDE threat modeling and produced CVSS-scored findings validated against MITRE Medical Device Playbook.
Firmware CVE Analysis STRIDE CVSS OT Security
02
JetBlue Critical Infrastructure Risk Model
Applied MBRA and Fault Tree Analysis to quantify $58.3M risk exposure across JetBlue's 14-node aviation network. Identified 2 critical nodes representing 51% of total risk. Designed $71.06M phased mitigation budget achieving 75% risk reduction. Produced NIST CSF-aligned KPI dashboards and interactive Python network graph.
MBRA Fault Tree NIST CSF Python Risk Quant
03
Incident Response Playbooks (SQL Injection & VPN Intrusion)
Authored 2 NIST 800-61-aligned IR playbooks for a corporate CSIRT. Defined escalation workflows, containment procedures, and evidence retention. Integrated MITRE ATT&CK techniques (T1659, T1021, T1571) into detection and triage with full communication matrices.
NIST 800-61 MITRE ATT&CK CSIRT SQL Injection VPN
04
Network Threat Detection Lab (ntopng / Snort)
Deployed and configured ntopng and Snort IDS/IPS to monitor live network traffic. Detected and analyzed brute-force attacks on SSH (Port 22), HTTP probe scans, FTP anonymous login attempts, and MySQL enumeration. Generated flow analysis reports with 75,000+ flagged emergency events.
Snort IDS ntopng Wireshark Netflow Brute Force

Astound Broadband OSINT Reconnaissance
Full-scope OSINT reconnaissance on Astound Broadband using passive enumeration techniques: Google dorking, Certificate Transparency (crt.sh), Amass subdomain enumeration, Shodan IoT scanning, and LinkedIn employee footprinting. Mapped 164+ exposed subdomains and proposed controls.
OSINT Shodan Amass Google Dork Recon

TLS / HTTPS Interception Lab (Burp Suite)
